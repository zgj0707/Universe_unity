# 广东区县铁路站点核对

核对日期：2026-11-11。当前筛选保留 91 个区县站、9 个原有城市站；罗湖及其他跨区域交界站由代码单独维护。原有城市站和交界站不是本次筛选对象。

以 [国铁客运时刻表 GTFS](https://github.com/wensimehrp/chinese-railway-gtfs) 2026-11-11 数据中的车站坐标为基础，补充 [OpenStreetMap 广东数据](https://download.geofabrik.de/asia/china/guangdong.html) 中可能存在的货运及其他铁路站，再与 [DataV 行政区边界](https://datav.aliyun.com/tools/atlas/) 进行空间匹配。坐标与边界存在不同坐标体系及数据误差，边界附近约 200 米纳入候选，不能视作官方站点名录。GTFS 数据采用 CC BY 4.0；OpenStreetMap 数据采用 ODbL。

有些地图数据的站点未标明经营者，可能属于地方铁路；为减少误删，先作为候选保留。规划中的高明站、湛江东站和盐田港专用铁路不视为已设国铁站。罗定铁路等候选项的经营归属、停用状态及临界点需要后续人工核验。
