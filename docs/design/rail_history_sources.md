# 19 世纪机车科技：年代资料

科技节点的年代分为“明确事件或馆藏年份”和“发展时期”两类。后者是用于组织游戏内容的近似时期，不表示发明、首次使用和全面推广发生在同一年。节点的收益百分比与前置关系是游戏设计，不是历史测量值或严格的技术谱系。

- [旅行者一号与斯托克顿—达灵顿铁路](https://blog.railwaymuseum.org.uk/shildon-the-cradle-of-the-railways-and-locomotion-no-1/)：1825 年公共铁路开通及 1828 年锅炉事故和重建。
- [火箭号与早期锅炉](https://blog.railwaymuseum.org.uk/agenoria-tracing-the-past/)：早期机车设计的差异与火箭号多烟管锅炉。
- [约翰牛机车](https://www.americanhistory.si.edu/collections/object/nmah_841968)：1831 年机车和美国前导轮改装。
- [布伦顿机械步行机车](https://blog.railwaymuseum.org.uk/eccentric-engineering/)：机械步行方案与 1815 年事故。
- [联杆配汽机构图纸](https://collection.sciencemuseumgroup.org.uk/documents/aa110002033/working-gear-for-no-359-341-344-345-346-347-348-376-377-380-381)：1842 年工作图。
- [拉姆斯博顿安全阀](https://collection.sciencemuseumgroup.org.uk/objects/co206318/safety-valve)：1856 年安全阀设计。
- [吉法尔注水器](https://collection.sciencemuseumgroup.org.uk/objects/co26717/gifford-injector-injector)：1858 年注水器。
- [西屋空气制动公司](https://www.loc.gov/collections/films-of-westinghouse-works-1904/articles-and-essays/the-westinghouse-world/the-westinghouse-air-brake-co/)：1869 年公司成立与后续空气制动改良。
- [霍尔特汽缸排水与泄压阀](https://collection.sciencemuseumgroup.org.uk/objects/co51170/holts-patent-cylinder-drain-and-relief-valve)：1878 年装置。
- [美国铁路安全装置](https://tile.loc.gov/storage-services/master/pnp/habshaer/ca/ca3100/ca3107/data/ca3107data.pdf)：1893 年铁路安全装置法背景。

此表覆盖新增节点的主要锚点，不是整个机车史的完整考证。涉及技术发展的约略年代、不同国家的首次使用与先后关系，后续仍需逐项补证。
