  $$\text{车辆日维护 } M_{\text{veh}} = N_{\text{车}} \times \overline{m}_{\text{车}}\quad (\text{初始基础 }\overline{m}_{\text{车}} = 28\text{ 金币/车/日})$$

### 2.2 收益递减上限（Diminishing Returns）数学公式
为彻底解决“百乃至千节点叠加导致后期数值指数级爆炸”的问题，**严禁将所有节点的百分比直接连乘或无上限累加**。按属性类别建立以下**双曲渐近软上限（Hyperbolic Soft Cap）**与**负指数成本底线（Exponential Floor）**：

设玩家在某属性维度 $k$ 已解锁的所有科技节点原始词条代数和为 $X_k = \sum x_{i,k}$：

1. **全线票务收入/票价溢价修正倍率 $E_{\text{rev}}(X_{\text{rev}})$**：
   $$E_{\text{rev}}(X_{\text{rev}}) = 1 + M_{\text{rev\_max}} \times \frac{X_{\text{rev}}}{X_{\text{rev}} + K_{\text{rev}}}$$
   - **参数设定**：最大上限增量 $M_{\text{rev\_max}} = 1.20$（即纯靠票务/服务科技带来的收入倍率最高封顶为 **$+120\%$**，总倍率上限 $2.20\times$），半饱和常数 $K_{\text{rev}} = 0.80$。
   - **递减表现**：
     - 当累计原始加成 $X_{\text{rev}} = 20\%$ 时，实际生效 $+24.0\%$；
     - 当累计原始加成 $X_{\text{rev}} = 80\%$ 时，实际生效 $+60.0\%$（达到上限的一半）；
     - 当累计原始加成 $X_{\text{rev}} = 240\%$（百/千节点后期）时，实际生效 $+90.0\%$，永远收敛于 $+120\%$ 以内。

2. **全局通用速度技术加成 $E_{\text{spd}}(X_{\text{spd}})$**：
   - 机车实物节点直接提供更高的**车辆基础速度**（如从 $24\text{ km/h}$ 提升至 $110\text{ km/h}$）；
   - 非机车的通用工程节点（如转向架、气门机构、制动器）提供的速度百分比加成同样采用双曲衰减：$M_{\text{spd\_max}} = 0.60$（最高额外提速 **$+60\%$**），$K_{\text{spd}} = 0.50$。
   - **轨道限速木桶约束**：当前已解锁轨道/桥梁科技决定的安全限速为 $V_{\text{track\_cap}}$，线路实际有效速度 $V_{\text{eff}} = \min\left(\overline{V}_{\text{配属车辆}} \times E_{\text{spd}}, \ V_{\text{track\_cap}}\right)$。

3. **车辆基础日维护减免倍率 $E_{\text{v\_maint}}(X_{\text{v\_save}}, X_{\text{v\_pen}})$**：
   $$E_{\text{v\_maint}} = \left[ 0.45 + 0.55 \times e^{-X_{\text{v\_save}}} \right] \times (1 + X_{\text{v\_pen}})$$
   - **参数设定**：维护费减免底线为 **$0.45\times$**（即无论解锁多少节煤、注水器、标准化零件科技，车辆维护最多降低 **$55\%$**，绝不会归零或变负数；而负效应 $X_{\text{v\_pen}}$ 独立乘算惩罚）。

4. **线路日维护费公式系数修正**：
   $$M_{\text{line\_final}} = 40 \times E_{\text{fixed}} + \left(0.25 \times E_{\text{dist}}\right) \times D + \left(5 \times E_{\text{sta}}\right) \times S$$
   - 距离维护系数 $0.25 \times E_{\text{dist}}$ 最低下限为 **$0.10$**（最多降低 **$60\%$**，通过贝塞麦钢轨、杂酚油防腐枕木、碎石道碴实现）；
   - 站点维护系数 $5 \times E_{\text{sta}}$ 最低下限为 **$2.50$**（最多降低 **$50\%$**，通过埃德蒙森车票、自动检票、站台规范化实现）。

5. **OD客流吸引与换乘阻抗减免**：
   - 换乘惩罚减免上限为 **$-70\%$**（至少保留 $30\%$ 换乘阻抗）；
   - 特定时段（夜间）与长途OD客流生成加成采用双曲软上限，最高使全网自然基础客流池扩容 **$+85\%$**。

### 2.4 2站短线 vs 12站干线：典型节点回本周期（Payback Period）精算对比
以下选取初、中、后期共 **6个代表性科技节点**，分别在 **2站初始短线（税后日利355）** 与 **12站合理干线（税后日利2909）** 上进行精确到小数点后两位的回本天数计算：

#### 算例1：【初期·降车辆维护】N010 塞甘多管火管锅炉（1826年，研发费 $420$ 金币）
- **节点效果**：车辆基础日维护 $-12\%$（原始词条 $X_{\text{v\_save}}=0.12$，按指数公式生效减免 $1 - [0.45 + 0.55\times e^{-0.12}] = 6.22\%$），线路速度 $+4\%$（通过缩短旅行时间使OD有效客流与票务收入 $+2.5\%$）。
- **在【2站短线】（1车，日维护88，日票务482.44）上的表现**：
  - 车辆维护节省：$28 \times 6.22\% = +1.74\text{ 金币/日}$
  - 提速带来票务增收：$482.44 \times 2.5\% = +12.06\text{ 金币/日}$
  - 税前日利润增量：$+13.80\text{ 金币/日}$ $\Rightarrow$ **税后日净增收（扣10%税）**：$13.80 \times 0.9 = \mathbf{+12.42\text{ 金币/日}}$
  - **2站线回本周期**：$420 / 12.42 = \mathbf{33.82\text{ 游戏日}}$（约 $3.38$ 小时；若2站配2车则为 **$28.4\text{ 游戏日}$**）。
- **在【12站干线】（6车，日维护368，日票务3600.22）上的表现**：
  - 车辆维护节省：$168 \times 6.22\% = +10.45\text{ 金币/日}$
  - 提速带来票务增收：$3600.22 \times 2.5\% = +90.01\text{ 金币/日}$
  - 税前日利润增量：$+100.46\text{ 金币/日}$ $\Rightarrow$ **税后日净增收**：$100.46 \times 0.9 = \mathbf{+90.41\text{ 金币/日}}$
  - **12站线回本周期**：$420 / 90.41 = \mathbf{4.65\text{ 游戏日}}$（仅需现实时间 $28$ 分钟！）。

#### 算例2：【初期·实物机车节点】N015 斯蒂芬森“火箭号”机车（1829年，研发费 $950$ 金币）
- **节点效果**：解锁“火箭号”购买权限并**免费赠送1辆**（单向区段运力 $+4200\text{ 人次/日}$，速度较早期矿山车提升 $+25\%$，单车日维护 $30$ 金币）。
- **在【2站短线】上的表现**：
