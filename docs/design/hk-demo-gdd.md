# 铁路大亨 2 · 香港箱庭 Demo（简明设计稿）

> 版本：v0.8（2026-11）｜平台：TapTap H5（Unity WebGL）｜引擎：Unity 6000.6.8f1
> 首版范围：只做香港一个箱庭区域。本文替代此前 800 行 v0.2 长稿，后续只用简洁 md。

## 1. 箱庭规则（本作地图基本法）

- 每张区域地图是**独立箱庭**：内部可自由连线，箱庭之间**不互通**。
- 跨区靠**地图边缘接口**：线路连到边缘「跨区口」，即视为修通到下一区域；进入下一区域后，在对应边缘生成同名接口，形成**伪互通**。
- 好处：每区一张手绘地图，美术可控；跨区接口天然做成「关卡出口」，不需要全球大地图。
- 香港箱庭接口：**罗湖 → 深圳**、**港珠澳 → 珠海/澳门**；后续区域从接口展开。

## 2. 香港箱庭内容（首版）

- 地形：港岛、九龙、新界、大屿山 + 维多利亚港；山海地形影响造价（山地 ×2、跨海 ×3）。
- 城市/车站（15）：中环、金钟、铜锣湾、北角、尖沙咀、旺角、九龙塘、红磡、沙田、大埔墟、荃湾、屯门、东涌、机场、迪士尼；边缘口：罗湖、港珠澳。
- 景观（6）：太平山、维多利亚港、浅水湾、狮子山（自然）；天坛大佛、庙街夜市（人文）。线路经过 80px 内进入「待打卡」，图鉴出现红点，不再自动弹窗。
- 国家/区域目标（demo 只显示进度）：开通 6 条线、连通 10 站、打卡 6 景。

## 3. 界面结构（demo 已实现）

- 顶栏：金币 +「每日收入」｜ 香港 + 时间（第 N 天 HH:MM + 倍速）｜ 钻石 + 加号 + 设置 + ?。
- 左列：任务 / 图鉴 / 排行；右列：收入×2 / 加速 / 领金币（广告位）。
- 地图：代码矢量绘制的箱庭底图（海岸线 + 等高线，无位图底图）+ 一代式圆点车站（已运营=金心墨环，未开通=白心墨环，跨区口=菱形）+ 细线线路 + 金色列车圆点 + 跨区箭头。
- 底栏 4 tab：线路 / 列车 / 公司 / 科技，全部进入整页。
- **不设建线模式**：长按车站 0.42s 触发震动 + 音效并开始拖线，经过车站以 44px 小热区自动吸附；拖回已连接站点会撤销后段，松手弹「开通确认」。
- **延长优先**：若起手车站已在某条线路上，确认弹窗默认「延长 X 号线」；多条线路经过该站时逐条列出可选，同时始终保留「开通新线路」。线路满 6 条时仍可延长，只是不能再开新线。
- **点线操作**：点线路弹出小气泡，按线路颜色区分；并行多条线时同时弹多个气泡。每个气泡提供「拆该段 / 拆整线 / 详情」。拆中间段会把线路拆成两条（受 6 条上限约束）；拆整线退款 60%。
- 线路页：每日收入/已连通/钻石概览 + 线路卡；线路详情页：客流/运力/每日收入三宫格、三项升级（页内直接购买）、沿线、加车/拆除。
- 车库页：每条线一张卡，车速/编组/班次三枚按钮。
- **公司页**：整页留白，内容待做。
- **科技树**：钢铁雄心 IV 式，每科目一页（机车/车辆/基建/电气化/经营），年份分列 2025/2030/2035，3×3 节点带前置连接线。
- 打卡：线路经过景观后只点亮图鉴红点；进入「图鉴」点击待打卡卡片，才领取明信片弹层（500×660）、附近车站客流 +15%、钻石 +20。

### 3.1 交互与视觉（v0.5）

- 开线：长按车站（0.42s）→ 震动 + 短音；橙色线跟手拖出，指尖圆点，进入 44px 吸附半径自动连接（目标站橙色光环 + 脉冲 0.24s，已连站粉色光环）；拖回已连接站点即撤销该站之后的路段；松手弹确认，取消即清空；不隐藏 dock、不切换模式条。
- 延长确认：弹窗上行列出可选线路与「开通新线路」，默认选中第一条可延长线路；点击行切换标题/收益预览；确认后扣钱并把新站接到该线，原有线路保留。
- 时间：60 秒 = 1 个运营日，时间显示在地区标题正下方（第 N 天 08:00 起）；倍速 1×/2×/3× 只放大进账，不改变 60 秒日长。
- 经济表现：列车在线路两端之间往返（三角波，车头朝向随方向翻转）；每到一站结一段，站上飘「+N」金字（上飘 38px/s，0.55s 后淡出）；左上角改为「每日收入」。
- 科技树：左侧五个科目 tab（当前科目墨色实心），年份三列，节点卡显示名称/RP/研究按钮，前置用短连线表示；研究后该卡变绿「已完成」。
- **克制原则**：页面不写说明性副标题、提示语、引导文案；必要说明收进右上「?」徽章弹窗（地图与每个整页都有）。
- 字号：页面标题 52、正文 24–34、按钮 28–38；地图站名 24、景观 22、区域 34；dock 36；确认/说明弹窗 24–32。
- 弹窗保留「开通确认」「说明」「打卡」「点线气泡 / 运营详情」；toast 缩到 620×68，停在顶栏下方，不再横穿地图。

## 4. 经济（demo 默认值）

- 初始：金币 2378、钻石 20、每日收入 240、预置 1 号线（中环—金钟—铜锣湾）。
- 单线每日收入 = 120 ×（站数−1）× 升级系数；总科技系数 +4%/项；景观每处 +8/天。
- 单段造价 = 30 + 图上距离 × 0.75；拆除退回 60%。
- 加车 289 起（每列 +120）；车库升级 136/204/289 起；研究点每 6 秒 +1。

## 5. Demo 操作

1. 长按地图车站约 0.4 秒（震动 + 音效）→ 拖到下一站，经过即自动连接；松手弹「开通确认」。
2. 从已有线路的车站起手时，弹窗默认延长该线路；有多条线经过则给出多选，也可选「开通新线路」。确认后扣钱通车，**停留在地图**，不自动跳转线路详情/加车页；需要加车时从底栏「线路」进入。
3. 若新线经过景观，不弹窗；图鉴图标出现红点，进入图鉴点击待打卡卡片领取。
4. 列车在两端之间往返，到站飘「+N」；可继续长按延长线路。
5. 点线路弹出按线路颜色区分的小气泡：拆该段 / 拆整线 / 详情；详情为大弹窗，显示近 7 日实收、今日实收、客流、运力与运营数据。
3. 底栏「线路 / 列车 / 公司 / 科技」进入整页；右上「?」看该页必要说明；左上 ← 返回。
4. 列车驶过景观附近 → 进入待打卡，图鉴红点；点击图鉴卡片领取。
5. 顶栏「1×」切换 1×/2×/3×，60 秒仍为一整天。

## 8. 如何运行（本地）

> 场景：工程只有 `Assets/Scenes/Main.unity`，里面只有 Bootstrap 空物体；地图与全部 UI 由 `DemoBootstrap` 在运行时生成，所以 Scene 视图本来没有画面，**按 Play 才能看到香港地图**。打开工程若没有有效场景会自动打开 Main，也可用菜单「铁路大亨2 / 打开主场景 Main」。运行时自动创建 UICamera + AudioListener，Game 视图不会再报无相机/无监听器。

```powershell
# 1) 构建 WebGL（Unity 6000.6.8f1）
& "E:\Unity\6000.6.8f1\Editor\Unity.exe" -batchmode -quit -projectPath "E:\aigc\Railway2_unity" -executeMethod DemoBuild.BuildWebGL -logFile "E:\aigc\Railway2_unity\Build\unity-build.log" -nographics

# 2) 本地起静态服务
cd E:\aigc\Railway2_unity\Build\WebGL
python -m http.server 8123

# 3) 打开 http://127.0.0.1:8123/
```

- 构建脚本：`Assets/Editor/DemoBuild.cs`；全屏 H5 模板：`Assets/Editor/WebGLTemplate.html`（构建后覆盖 `index.html`）。
- 运行时 UI 全部代码生成：`Assets/Scripts/DemoBootstrap.cs`；字体 `Assets/Resources/Fonts/LXGWWenKai-Regular.ttf`（OFL）。
- WebGL 关闭压缩，方便本地静态服务直接跑。

## 10. 性能与构建注意

- 首次 WebGL+IL2CPP 构建约 4–5 分钟；后续增量约 3 分钟。
- 构建时 Unity/Bee/IL2CPP 会吃满 CPU；建议限核 + BelowNormal 优先级，避免整机卡顿。
- 地图底图由 UGUI 矢量网格在启动时生成（`MapPolygonGraphic` 填色 + `MapStrokeGraphic` 画海岸线/等高线/海浪），不使用位图底图；仅顶部/底部渐隐仍用 1×64 运行时光栅；字体为 24MB 动态字体，后续可做子集化减小包体。
