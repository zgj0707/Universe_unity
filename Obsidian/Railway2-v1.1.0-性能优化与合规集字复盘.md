# Railway2 v1.1.0 性能优化与合规集字工程复盘

## 1. 全量纯虚构地名合规与书画集字
- **全图 161 站 + 21 府 + 3 大区合规替换**：彻底脱离现实地名与宗教词汇，按区域气质虚构为「汐港」（山海港湾）、「镜屿」（青花海湾古街）、「榕川」（骑楼春潮水乡），并在 `DemoSave.LegacyPlaceNames` 保留历史存档自动迁移。
- **开源可商用书法集字**：采用 Google Fonts SIL OFL 开源字体（`Zhi Mang Xing` / `Liu Jian Mao Cao` / `Ma Shan Zheng`）生成 `680×256` 白字透明底遮罩 `region_title_*.png`，配合四向柔光外轮廓去除椭圆底衬与冗余副标题。
- **玩家自定义改名**：`Station.customName` 与不可变 `StationSaveKey` 隔离，接入 `DemoSave` 读写与 `DemoUndo` 撤回栈，大区名保持固定不可自定义。

## 2. 路网规则与交通经济重平衡
- **交界站开放过站/插站 + 抑制双交界直达**：解除交界站只能做起终点的限制，仅保留“禁止 `portal ↔ portal` 相邻直连”护栏以防止 `SegmentRegion` 归属二义性；同步在 OD 矩阵、拖拽热力与新增客流预估中将双交界站直达需求抑制为 `12%`。
- **分区域真实地理比例尺映射**：依底图经纬度投影与现实跨度按分段所在大区换算公里数（榕川 `0.68 km/px`、汐港 `0.050 km/px`、镜屿 `0.00954 km/px`）。
- **「榕川」省域客流与盈利重塑**：拉升地级府城与县镇 `CityDemandWeight`，平滑省内 114 站距离分母防预算被未连站点稀释，提升长途城际里程票价系数并降低时间阻抗。
- **科技树成长曲线重塑**：打破 `ResearchAmount` 50% 硬上限双曲线（正向放宽至 `185%`、减免至 `72%`），引入按造价对数增长的节点效用放大（工程树与企业治理 105 节点同步），消除后期几十万换几十块的倒挂。

## 3. UI 交互精简与性能攻坚（Codex 联合诊断 + 监督落地）
- **交互提效**：
  - 调度页 & 线路页接入归属筛选（线路页默认当前区）+ 多维排序 + 「定位起点 ▸」跨区跳转；
  - 线路详情页将「机车配属」与「票价调度」直接以可折叠下拉面板内嵌，原地刷新；
  - 机车商店新增 `×1 / ×5 / ×10` 批量购入与单步撤销；
  - 收益跳字修复 Unity `VerticalWrapMode.Overflow` 裁切问题，低画质屏蔽、高画质随机抽跳；
  - 移除无意义英文装饰、冗余副标题与科技树“日利润预计”鸡肋弹窗。
- **性能卡顿彻底治理（P0 → P1 → P2）**：
  1. **松手帧去计算**：`ShowConnectPopup` 延迟至下一帧并改用局部粗估，取消松手瞬间四时段全网重算；
  2. **真·时间片切片与同版本提交**：`CalculateTraffic` / `RunDijkstraPass` 支持约 `2ms/帧` 暂停步进；分离暂存 `stagedSlots` 与正式 `forecastSignature`，消除治理树 `hasForecastSignature = false` 绕过分帧及新旧时段混算漏洞；
  3. **科技树增量局部避让**：`HistoryGraphLayout` 移除 `Add()` 时的 `IsSleeping = true` 急刹车，新节点 `1ms` 局部找位且保留其余节点柔和漂移，单帧避碰由 16 轮降至 3 轮；
  4. **异步序列化与防抖落盘**：`DemoUndo` 改用 `RequestSaveGame` 防抖合并写盘，移除开线/延线重复 `SaveGame()`，后台线程序列化 JSON，切后台/退出仍同步兜底。
